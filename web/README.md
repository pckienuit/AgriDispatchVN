# web/

Thư mục tài sản tĩnh. Server phục vụ nội dung ở đây; file dotfile bị chặn.

## Trạng thái

- Chỉ có tài liệu này. Không có `index.html`, nên `/` trả 404. Khi được giao task frontend, thêm HTML/CSS/JS tại đây; server phục vụ `index.html` mặc định.
- Giao diện đang được nhóm UX/UI thiết kế lại. Chưa đưa demo hay frontend cũ vào.
- Không đặt dữ liệu khảo sát, thông tin cá nhân hay secret vào đây; mọi thứ trong `web/` có thể được phục vụ công khai.
